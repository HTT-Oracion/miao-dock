# R6 真机验收清单（番剧十屏 + 真播矩阵）

> 用途：本环境只能跑无头门禁（tsc / eslint / cargo test / e2e service / 静态断言），**看不到画面**。
> R6 由人在本机按这份清单点一遍；把「问题条目」贴回来，按条目修。
>
> 记录原则：**一条问题 = 屏 / 步骤 / 期望 / 实际 / 证据**。没有证据（截图或错误文本）的条目按"未复现"处理。

## 0. 前置（5 分钟）

| # | 步骤 | 期望 |
|---|---|---|
| 0.1 | `npm run tauri -- dev`（或装好的 exe） | 主窗口起来，侧栏有「番剧」 |
| 0.2 | 设置 → 番剧 → 库根指向一个**有视频文件**的目录（或点「导入本机文件夹」） | 库根写进设置并重启动漫服务，扫描出条目 |

## 1. 十屏逐项

### ① 探索（explore）
- [ ] 时间表 / 热度两块有**真数据**（不是骨架、不是写死的示例标题）
- [ ] 搜索框输入中文能出候选；点候选能建库并跳到详情
- [ ] 筛选条：年份 / 季度 / 排序 / 布局切换都生效；标签 chip 只来自当前结果
- [ ] 断网时：给出"拉不到"的明确文案，**不是**空列表

### ② 收藏（collection）
- [ ] 四种收藏态（在看 / 想看 / 看过 / 搁置）切换后**重进屏仍在**
- [ ] 卡片进度百分比与「看过 N 话」对得上

### ③ 详情（detail）
- [ ] 评分三数（评分 / 排名 / 收藏人数）都有值；缺字段显示「—」而不是 0
- [ ] 角色 / 制作人员 / 关联作品三块有数据或明确空态
- [ ] 「候选元数据」面板：检索 → 选一条 → 应用后标题/封面**真的变**
- [ ] 评论区域：说明文案（本期只读），不是假评论

### ④ 播放（player）
见下面 §2 真播矩阵。另外：
- [ ] 选集侧栏：切集不黑屏、进度条归零、标题跟着换
- [ ] 「选择播放来源」浮层：本地 / 媒体服务器 / 在线网页源 / 订阅 / BT 五组都出现
- [ ] 关掉「切来源前确认」后点播放**直接播**；打开后**先问一句**
- [ ] 音量滑杆 + 滚轮、跳过 OP/ED 按钮可用
- [ ] 统计面板：缓存 / 丢帧 / 码率 / 解码器（内核轨才有真实数字；WebView 轨显示"不可用"要说明）

### ⑤ 缓存（cache）
- [ ] 播放器控制条「缓存这一集」→ 缓存屏出现任务，进度**真的在涨**
- [ ] 暂停 → 进度停住；继续 → 从断点续（不是从 0）
- [ ] 删除 → 任务消失且**盘上文件也没了**
- [ ] 失败任务显示具体原因（不是"失败"两个字）
- [ ] 空态只在真的没任务时出现

### ⑥ 历史（history）
- [ ] 看完/看到一半的集出现在历史里，时间与位置对得上
- [ ] 点历史条目能续播到那个位置

### ⑦ 账号（account）
- [ ] 邮箱登录：错密码给 401 文案；对密码进入登录态
- [ ] 设备码 / 扫码：出码 → 「模拟另一端确认」→ 变登录态
- [ ] 「立即同步」：队列条目被推走，云端计数增加
- [ ] 冲突：用旧值覆盖同一条 → 按设置里的策略处理并在面板列出两侧值
- [ ] 退出登录：回到未登录，本地库**不受影响**

### ⑧ 数据源（source）
- [ ] 内置本地源恒在且健康
- [ ] 添加一个通用网页源（列表/链接/标题/视频地址四条选择器）→ 「测试」能取到条目
- [ ] 详情页解析直链 → 播放器能播
- [ ] 订阅导入：填一个返回 `{name,kind,url,rules}` 的地址 → 草稿填进编辑器
- [ ] BT：贴磁力 → 任务出现、进度涨、分享率显示；「播放」能起播（边下边播）
- [ ] 关掉「允许 BT 下载」后添加磁力**被拒并说明**
- [ ] PikPak 面板写「未接入」，不是"暂无任务"

### ⑨ 三态页（states）
- [ ] 未装配 / 未就绪 / 不可用三种形态都能看到，且文案说清"下一步做什么"

### ⑩ 设置（settings）
- [ ] 番剧分组 34 项都在，改完**重进仍在**
- [ ] 标题模式（中文名/原名）切换后卡片标题真的变
- [ ] 优先分辨率：多清晰度页面按它挑（缺档就近降级）
- [ ] BT 端口改成数字 → 重启动漫服务后 BT 会话监听该端口；改回「随机」→ 随机端口
- [ ] 限速改成 1024 → 下载速度明显被压；改回 0 → 恢复
- [ ] 做种上限设 0.1 → 完成的任务到分享率就暂停

## 2. 真播矩阵（R6-2）

| 素材 | 轨道 | 期望 | 验过 |
|---|---|---|---|
| mp4（H.264/AAC） | WebView | 能播、能拖、进度回写 | ☐ |
| mkv（H.265/多音轨） | 内核 | 能播（独立窗口）、切音轨生效 | ☐ |
| mkv + 外挂 ass | 内核 | 字幕渲染正确（样式不丢） | ☐ |
| 内嵌字幕（多轨） | 内核 | 按「字幕语言优先级」自动选一条 | ☐ |
| HLS（m3u8 相对分片） | WebView | 能播（分片地址被改写） | ☐ |
| 任意一集 | 内核 | 截图落盘、倍速夹取（0.25–4.0） | ☐ |
| 任意一集 | 两轨 | 续看回写：退出重进从上次位置继续 | ☐ |

> 内核轨是**独立窗口**（D-251）。如果期望"画面嵌在应用窗口里"，那就是 R1 的嵌入式渲染，
> 不在本清单范围 —— 见 `docs/internal/spec-notes-1.md` 里 R1 的登记。
